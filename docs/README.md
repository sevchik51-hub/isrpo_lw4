- [прямоугольник](#rectanglepy)
- [круг](#circlepy)

## **В репозитории хранятся:**
---

- # circle.py  

- ### **area(r):**
  >Вычисляет площадь круга  
  Использует библиотеку math для числа pi (math.pi)
  - r - (число) радиус окружности
  
  Пример вызова функции:
  
  ```py
  print("Area = ", area(3)) # Area = 28.274333882308138
  #Выведет в терминал площадь круга с радиусом 3
  ```
- ### **perimeter(r):**
  >Вычисляет длину окружности
  Использует библиотеку math для числа pi (math.pi)  

  - r - (число) радиус окружности
  

  Пример вызова функции:

  ```py
  print("Perimeter = ", perimeter(3)) # Perimeter =  18.84955592153876  
  #Выведет в терминал длину окружности с радиусом 3
  ```

- # rectangle.py  

- ### **area(a, b):**
  >Вычисляет площадь прямоугольника

  - a - ширина прямоугольника  
  - b - высота прямоугольника

  Пример вызова функции:
  
  ```py
  print("Area = ", area(3, 4)) # Area = 12
  #Выведет в терминал площадь прямоугольника со сторонами 3 и 4
  ```
- ### **perimeter(a, b):**
  >Вычисляет периметр прямоугольника  
  - a - ширина прямоугольника  
  - b - высота прямоугольника
   

  Пример вызова функции:

  ```py
  print("Perimeter = ", perimeter(3, 4)) # Perimeter =  14  
  #ВВыведет в терминал периметр прямоугольника со сторонами 3 и 4
  ```
  ---
  ---  

- # square.py  

- ### **area(a):**
  >Вычисляет площадь квадрата  
  - a - сторона квадрата  
  
  Пример вызова функции:
  
  ```py
  print("Area = ", area(5)) # Area = 25  
  #Выведет в терминал площадь квадрата со стороной 5
  ```
- ### **perimeter(a):**
  >Вычисляет периметр квадрата  
  - a - сторона квадрата  
   

  Пример вызова функции:

  ```py
  print("Perimeter = ", perimeter(5)) # Perimeter =  20  
  #ВВыведет в терминал периметр квадрата со стороной 5
  ```
  ---
  ---  

- # triangle.py  

- ### **area(a, h):**
  >Вычисляет площадь треугольника  
  - a - сторона треугольника
  - h - высота, опущеная на эту сторону 
  
  Пример вызова функции:
  
  ```py
  print("Area = ", area(3, 4)) # Area = 6  
  #Выведет в терминал площадь треугольника со стороной 3 и высотой 4
  ```
- ### **perimeter(a, b, c):**
  >Вычисляет периметр треугольника  
  - a - первая сторона треугольника
  - b - вторая сторона треугольника
  - c - третья сторона треугольника 
   

  Пример вызова функции:

  ```py
  print("Perimeter = ", perimeter(3, 4, 5)) # Perimeter =  12  
  #ВВыведет в терминал периметр треугольника со сторонами 3, 4, и 5  
  ```
